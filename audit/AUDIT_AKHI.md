## Method

Each cited `source_url` was opened fresh (WebFetch/WebSearch only; no curl/python fetching; researcher notes and other audit files not read). An item is CONFIRMED only when the page itself shows the claim. Presence "No" cells: the utility's own residential/business rate, program and DR pages were searched; CONFIRMED when nothing qualifying was found. Program rows: name, category, $ value + units, status and URL checked. Where the cited URL did not support a true claim, one replacement search on the utility's own site was allowed; the item is then CONFIRMED and the citation is logged below as a source defect. A stale dollar figure (superseded by a newer value on the cited page) counts as a wrong $. INCONCLUSIVE = page unreadable or the claim's status cannot be shown either way.
