## Method

- Read audit/RUBRIC.md and SCAN_SCHEMA.md only; no researcher notes or other audit files.
- Each cited source_url opened fresh with WebFetch. Yes cells: CONFIRMED only if the page itself shows the program for that segment, currently offered; if the page was dead/JS-only/did not show it, one search of the utility's own site for a replacement, then CONFIRMED (replacement URL given) or REFUTED/INCONCLUSIVE.
- No cells: utility's own rates/program/tariff pages searched; REFUTED if a program was found.
- Program rows: name, category (per data/processed/programs_SCHEMA.md vocabulary), $ value + units, status, source. $ figures matching only a dated (2021/2022/2024) document where a newer tariff exists were treated as stale (wrong_dollar) when the newer value was found, else INCONCLUSIVE.
- Domains that returned 403/robots/JS-only shells (ladwp.com main site, co.my.xcelenergy.com, nvenergy.com program pages, files.cityofredding.gov) -> INCONCLUSIVE unless an alternate page on the utility's domain was readable.
- Raw verdicts: audit/results/West.json.
